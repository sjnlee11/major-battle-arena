AI 전공 배틀 아레나

자료를 올리면 AI가 퀴즈를 내고, 공부가 곧 전투가 되는 RPG형 학습 플랫폼
해커톤 · 주제: AI 학습 기반 학습 지원 서비스

01타겟 사용자

공부를 재미있게 하고 싶은 대학생 누구나

  • 인문·사회·교육·자연·공학·예체능·의약 7개 전공 계열 모두 사용 가능
  • PDF·TXT·DOCX 강의자료만 있으면 전공 무관하게 시작
  • 혼자 하는 시험 공부가 지루한 학생, 친구와 함께 경쟁하며 공부하고 싶은 학생

02어떤 문제를 풀었나

기존 AI 서비스(ChatGPT 등)로 공부하면…

  • 할 수 있는 건 단순 자료 요약과 단순 퀴즈 생성뿐
  • 틀린 문제를 반복해서 풀려면 매번 프롬프트를 다시 입력해야 함 (오답 기록이 남지 않음)
  • 무엇보다 지루하다 → 꾸준히 하기 어렵고, 보상·성장·경쟁이 없음

▶ “공부는 AI가 해주지만, 계속 하게 만드는 건 아무도 안 해준다.”

03해결 아이디어

강의자료 → AI 출제 → 전투 → 오답 자동 저장 → 재도전 의 학습 루프를 게임 하나에 담았습니다.

  • 프롬프트 입력 없이 버튼 한 번으로 출제·채점·오답 복습
  • 학습을 전투·경험치·레벨·골드로 바꿔 지속 동기 부여
  • 랭킹·친구·채팅·PvP로 함께 공부

04기존 AI 학습 vs AI 전공 배틀 아레나

기존 AI 서비스로 공부AI 전공 배틀 아레나
문제 생성원하는 문제를 직접 프롬프트로 요청자료 선택 + 난이도·유형(OX/객관식/단답/서술)·문항 수만 고르면 AI가 자동 출제
오답 복습틀린 문제를 기억해 다시 입력해야 함틀린 문제는 자동 저장 → ‘오답 던전’·‘보스 레이드’로 반복 도전
피드백정답/해설 나열서술형 AI 채점·첨삭 + 패배 시 AI 전술 조언(약점 진단·공략법·반격 루트)
